# Ipl-Match-Analysis

## Project Overview 
  This project is based on IPL match data analysis using python and pandas.

* analysis IPL match 2024 datasets
* Display match record
* toss wining team
* match winner team
* calculate team wise total win
* analysis most wicket taking players in every match

## Technologies & Tools used

* Programming language: Python
* Library: Pandas(for data loading,filtering and data manipulation)
* NumPy: Numerical Operations
* google Colab: Project development

 ## Dataset
 * File:ipl2024 match.csv
 * Formate:CSV(comma-Seprate values)


## Features
  * Overall match overview (total match, seasons and cites)
  * Team analysis ( matches played,wins and wins percentage)
  * Player analysis (top player of the match awards)
